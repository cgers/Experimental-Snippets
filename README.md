# Experimental-Snippets

A collection of interesting code snippets on different topics and ideas. This repository contains well-documented examples of algorithms, data structures, design patterns, utilities, and mathematical operations.

## 📁 Repository Structure

### Algorithms
- **fibonacci_memoization.py** - Efficient Fibonacci implementation using memoization and decorators
- **binary_search.py** - Binary search with multiple variations (standard, leftmost, rightmost, recursive)

### Data Structures
- **trie.py** - Trie (prefix tree) implementation for efficient string operations
- **lru_cache.py** - Least Recently Used (LRU) cache with O(1) operations

### Design Patterns
- **observer.py** - Observer pattern for event-driven programming
- **singleton.py** - Thread-safe Singleton pattern implementation

### Utilities
- **retry_decorator.py** - Retry decorator for handling transient failures
- **timer_context_manager.py** - Context manager for timing code execution

### Math
- **matrix_operations.py** - Matrix multiplication, transpose, and determinant calculations

## 🚀 Usage

Each snippet is self-contained and can be run independently. Simply execute any Python file to see example usage:

```bash
python algorithms/fibonacci_memoization.py
python data-structures/trie.py
python design-patterns/observer.py
```

## 📝 Features

- **Well-documented**: Each snippet includes detailed docstrings and comments
- **Runnable examples**: All files include example usage in the `__main__` block
- **Time/Space complexity**: Algorithms include complexity analysis
- **Best practices**: Demonstrates Python idioms and design patterns

## 🎯 Purpose

This collection serves as a reference for:
- Learning and teaching programming concepts
- Quick reference for common algorithms and patterns
- Code examples for interviews and discussions
- Experimentation with different approaches and techniques
