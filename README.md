# Experimental-Snippets

A collection of code snippets and classes I find interesting - often from ChatGPT or an AI.

## Overview

This repository contains useful code snippets organized by programming language. Each snippet is self-contained and includes documentation about its purpose and usage.

## Structure

```
snippets/
├── python/       # Python snippets
├── javascript/   # JavaScript/Node.js snippets
├── java/         # Java snippets
├── cpp/          # C++ snippets
├── csharp/       # C# snippets
└── other/        # Other languages or multi-language examples
```

## Contributing

Feel free to add your own interesting snippets! Each snippet should:

1. Be self-contained and runnable
2. Include comments explaining what it does
3. Include example usage if applicable
4. Credit the source (e.g., "AI-generated", "From ChatGPT", etc.)

## Examples

Check out the `snippets/` directory for example snippets in various languages.
