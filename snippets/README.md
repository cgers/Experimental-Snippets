# Snippets

This directory contains code snippets organized by programming language.

## Structure

- `python/` - Python code snippets
- `javascript/` - JavaScript and Node.js snippets
- `java/` - Java code snippets
- `cpp/` - C++ code snippets
- `csharp/` - C# code snippets
- `other/` - Snippets in other languages or multi-language examples

## Adding Snippets

Each snippet should be a self-contained file with:
1. A descriptive filename
2. Comments explaining what the snippet does
3. Example usage if applicable
4. Source attribution (e.g., "From ChatGPT", "AI-generated", etc.)
